# Security policy

## Supported versions

Security fixes are made on the latest released version of SlurmBar. Please reproduce the issue
against the current `main` branch when practical.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting flow:

1. Open the repository's **Security** tab.
2. Choose **Report a vulnerability**.
3. Include the affected version, impact, reproduction steps and any suggested mitigation.

Do not disclose the vulnerability in a public issue. If the private reporting button is not
available, open an issue containing only a request for a private security contact and no
technical details.

You should receive an acknowledgement within seven days. Confirmed reports will be handled in a
private advisory until a fix and coordinated disclosure are ready.
